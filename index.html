Aprende lógica de programación jugando 🎮

Cinco misiones cortas para entender cómo "piensa" un programa web.

Cómo usar esta guía
  1. Lee el apartado "¿Qué es y para qué sirve?" para entender la idea.
  2. Juega con el ejemplo animado. No puedes romper nada.
  3. Sigue las instrucciones paso a paso para cumplir la misión.
  4. Gana la estrella y pasa al siguiente tema. Al final tienes un glosario para repasar.

1Variables: cajas con nombre

Una variable es un espacio de la memoria con nombre, donde guardas un dato para usarlo después.

📖 ¿Qué es y para qué sirve?

Imagina una caja con una etiqueta. La etiqueta es el nombre (vidas) y lo que hay dentro es el valor (3). Con let creas la caja y con = le metes un dato. Después puedes leerla o cambiarla.

Tipos de dato más comunes: número (5), texto ("Ana", siempre entre comillas) y booleano (true o false).

🌐 Dónde la verás en una página web
  • Una tienda guarda el total de tu carrito.
  • Un juego guarda tus puntos.
  • Una red social guarda tu nombreDeUsuario.
let vidas = 3;
🎯 Misión: deja la variable vidas con valor 5.
🧭 Instrucciones paso a paso
  1. Mira el código negro: let vidas = 3; significa "crea una caja llamada vidas y guarda un 3".
  2. Pulsa el botón morado para sumar una vida o el naranja para restar una.
  3. Observa que el número del código y los corazones cambian a la vez.
  4. Cuando vidas valga 5, ganas la estrella.
⚠️ Errores comunes
  • Vidas y vidas son variables distintas: las mayúsculas importan.
  • vidas = vidas + 1 no es una ecuación. Significa: toma lo que hay en la caja, súmale 1 y guárdalo de nuevo.
  • Un texto sin comillas se confunde con el nombre de una variable.

2Condicionales: decidir según el caso

Un condicional permite que el programa decida qué hacer según la situación.

📖 ¿Qué es y para qué sirve?

if hace una pregunta que solo se responde con verdadero o falso (la condición). Si es verdadera, ejecuta su bloque. Si no, el programa prueba con el siguiente else if, y else atrapa "todo lo demás". Solo se ejecuta un camino.

Operadores para comparar: < menor, > mayor, >= mayor o igual, === igual, !== distinto.

🌐 Dónde la verás en una página web
  • Mostrar "Contraseña incorrecta" solo si no coincide.
  • Dar un descuento si el carrito pasa de $500.
  • Mostrar el botón "Cerrar sesión" solo si ya iniciaste sesión.
🧍👕
22 °C


🎯 Misión: mueve la temperatura hasta ver al personaje con abrigo y también con gafas.


🧭 Instrucciones paso a paso
  1. Arrastra el control deslizante.
  2. Mira el código: la línea resaltada en amarillo es el camino que el programa está ejecutando.
  3. Baja de 15 °C para activar el abrigo 🧥.
  4. Sube a 30 °C o más para activar las gafas 😎.
  5. Cuando hayas visto ambos casos, ganas la estrella.


⚠️ Errores comunes
  • = guarda un valor y === compara. Confundirlos es el error número uno.
  • El orden importa: se revisa de arriba abajo y se detiene en la primera condición verdadera.
  • Con exactamente 15 °C no se cumple temp < 15, porque 15 no es menor que 15.





3Bucles: repetir sin copiar y pegar


Un bucle repite una acción sin que tengas que copiarla una y otra vez.


📖 ¿Qué es y para qué sirve?
El bucle for tiene tres partes dentro del paréntesis:
  • let i = 0: inicio, el contador empieza en 0.
  • i < n: condición, mientras sea verdadera, sigue repitiendo.
  • i++: paso, suma 1 al contador en cada vuelta.
Cada repetición se llama iteración.


🌐 Dónde la verás en una página web
  • Dibujar los 20 productos de una tienda a partir de una lista.
  • Revisar cada campo de un formulario para ver si está vacío.
  • Crear las filas de una tabla de calificaciones.




Vueltas:  




🎯 Misión: elige cuántas vueltas necesita el robot para llegar a la bandera 🚩.


🧭 Instrucciones paso a paso
  1. El robot empieza en la casilla 0 y la bandera está en la casilla 6.
  2. Escribe en "Vueltas" cuántas veces debe repetirse avanzar().
  3. Pulsa Ejecutar y mira cómo se resalta avanzar() en cada vuelta.
  4. Cada vuelta mueve al robot una casilla. Si se queda corto, sube el número; si se pasa, bájalo.
  5. Cuando caiga justo en la bandera, ganas.


⚠️ Errores comunes
  • Bucle infinito: si la condición nunca se vuelve falsa, la página se congela.
  • Empezar en 0 o en 1 cambia el número de vueltas por uno.
  • i < 5 repite 5 veces desde 0; i <= 5 repite 6.





4Funciones: máquinas que transforman


Una función es un bloque de pasos con nombre que puedes usar todas las veces que quieras.


📖 ¿Qué es y para qué sirve?
Una función recibe datos (llamados parámetros), los procesa y devuelve un resultado con return. Piensa en una licuadora: entran frutas, sale jugo.
Definir y llamar son cosas distintas: function triple(n) crea la máquina; triple(8) la enciende. La ventaja: escribes la lógica una vez y evitas repetir código.


🌐 Dónde la verás en una página web
  • calcularTotal(precio, cantidad) en una tienda.
  • validarCorreo(texto) en un formulario de registro.
  • mostrarMensaje(texto) para avisos en pantalla.


function triple(n) {
  return n * 3;
}


? ➜ ⚙️ ➜ ?


triple(  ) 


🎯 Misión: llama a la función con un número para que devuelva 24.


🧭 Instrucciones paso a paso
  1. Lee el código: n es el parámetro y return n * 3 es lo que sale de la máquina.
  2. Escribe un número dentro de triple( ).
  3. Pulsa Llamar: el número entra a la máquina ⚙️ y sale el resultado.
  4. Pista: ¿qué número multiplicado por 3 da 24? Prueba con 24 ÷ 3.


⚠️ Errores comunes
  • Olvidar return: la función no devuelve nada y obtienes undefined.
  • Definir una función y nunca llamarla: no pasa nada.
  • Olvidar los paréntesis al llamarla: triple no es lo mismo que triple(8).





5Eventos: la página reacciona


Un evento es algo que ocurre en la página, y tu código decide cómo reaccionar.


📖 ¿Qué es y para qué sirve?
Un evento puede ser un clic, pasar el mouse o pulsar una tecla. Con addEventListener("tipo", función) le dices al navegador: "cuando ocurra esto, ejecuta esta función".
Para cambiar la página, JavaScript usa el DOM: la página convertida en un árbol de objetos que se pueden leer y modificar. Eventos comunes: click, mouseenter, input, keydown, submit.


🌐 Dónde la verás en una página web
  • Un menú que se abre al hacer clic en el ícono.
  • Un formulario que avisa mientras escribes tu contraseña.
  • Una galería que cambia de foto con las flechas del teclado.


boton.addEventListener("click", ...);
caja.addEventListener("mouseenter", ...);
campo.addEventListener("input", ...);


Pasa el mouse por aquí


🎯 Misión: dispara los tres eventos.

  • click
  • mouseenter
  • input


🧭 Instrucciones paso a paso
  1. Pulsa el botón "Haz clic aquí" (evento click).
  2. Pasa el mouse por la caja punteada (evento mouseenter).
  3. Escribe cualquier letra en el campo de texto (evento input).
  4. Cada evento que dispares se marca con ✔ en la lista. Con los tres, ganas.


⚠️ Errores comunes
  • El nombre del evento va entre comillas y sin "on": "click", no onclick.
  • La función se pasa sin paréntesis: addEventListener("click", saludar).
  • El elemento debe existir en la página antes de ponerle el evento.



🏆 ¡Terminaste!
Ya conoces los cinco bloques con los que se construye cualquier programa web: variables, condicionales, bucles, funciones y eventos.


📚 Glosario y resumen


Variable
Caja con nombre que guarda un dato. let edad = 19;


Valor / tipo de dato
Lo que hay dentro de la caja: número, texto o booleano.


Booleano
Un dato que solo puede ser true o false.


Condición
Pregunta que se responde con verdadero o falso. Se usa en if.


Bucle / iteración
Bloque que se repite; cada repetición es una iteración.


Parámetro
Dato que una función recibe para trabajar.


Función
Bloque de pasos con nombre. Se define una vez y se llama muchas.


Evento
Algo que ocurre en la página: clic, tecla, mouse encima.


DOM
La página vista como objetos que JavaScript puede cambiar.


Resumen: guardas datos en variables, decides con condicionales, repites con bucles, reutilizas con funciones y reaccionas al usuario con eventos.
